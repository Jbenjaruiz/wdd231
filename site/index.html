Website Plan: Alma Motera

Site Name

Alma Motera

This name translates to "Motorcycle Soul" in English. It was selected because it represents the deep passion and personal connection that enthusiasts have with motorcycling, which is the core theme of the website.

Site Purpose

The site's purpose is to be a dedicated hub for motorcycle hobbyists. It will provide visual inspiration through a dynamic photo gallery, educate visitors on different motorcycle styles, and offer a curated list of resources to connect users with the broader motorcycling community. The content aims to celebrate the freedom, design, and culture of motorcycles.

Scenarios

  • "What are the main differences between a cruiser and a touring bike for long-distance travel?"
  • "Where can I find high-quality photos for inspiration for my own custom bike project?"

Color Schema

The color scheme is designed to be modern and bold, reflecting the materials and atmosphere of motorcycling—asphalt, metal, and vibrant highlights.

  • Asphalt Black (#212121): Used for the main page background, creating a dark, immersive theme.
  • Ghost White (#F4F4F4): Used for all primary body text. This provides high contrast against the dark background for excellent readability.
  • Blaze Orange (#FF6600): A vibrant accent color used for main headings (h1), links, and key interactive elements to draw attention and add a splash of energy.

Typography

The typography choices balance strong, impactful headings with a clean, highly readable font for body content.

  • Headings (h1, h2): Oswald. This condensed, bold sans-serif font is used for its strong, mechanical look, perfect for titles.
  • Body and General Text (p, li): Roboto. This sans-serif font is chosen for its exceptional clarity and readability on screens, making it ideal for paragraphs and lists.

Wireframe

The homepage is designed to be visually impactful and easy to navigate on both mobile and desktop screens.
